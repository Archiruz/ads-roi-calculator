# Business Logic & Mathematical Specification: AdForecast Pro (ROI Advertising Calculator)

## 1. Overview & Purpose

This document outlines the business rules, definitions, mathematical formulas, and numerical constraints powering the **ROI Advertising Calculator (AdForecast Pro)**.
The formulas have been independently researched and precisely aligned with the reference mockups (`ui1.png` and `ui2.png`), ensuring consistency between the frontend real-time interactive preview, backend persistence engine, and automated regression test suites.

| Parameter                     | Identifier            | Type                      | Unit     | Range / Constraints                              | Default Value | Description                                                                                                                        |
| :---------------------------- | :-------------------- | :------------------------ | :------- | :----------------------------------------------- | :------------ | :--------------------------------------------------------------------------------------------------------------------------------- |
| **Harga Produk**              | `product_price`       | Numeric (`DECIMAL(12,2)`) | IDR (Rp) | Min: `0`, Max: `100,000,000,000`                 | `500,000`     | The catalog price of the digital or physical product sold.                                                                         |

## 3. Predicted Outputs (Hasil Prediksi)

### 3.1. Jumlah Results (Conversions / Orders)

- **Concept**: The total number of customer acquisitions / transactions generated by the monthly ad spend at the current Cost Per Result.
- **Formula**:
  $$\text{results\_count} = \frac{\text{monthly\_ad\_spend}}{\text{cpr}}$$
- **Display Rule**:
    - In visual UI cards: rounded to integer $\lfloor \text{results\_count} \rfloor$ or rounded normally for display.
    - In downstream revenue calculation: retains full precision so that `results * AOV` matches exact campaign totals.
- **Mockup Verification**:
    - Example 1: `Rp 1,500,000 / Rp 235,000` = `6.3829` $\rightarrow$ Displays **6** results.
    - Example 2: `Rp 5,000,000 / Rp 100,000` = `50` $\rightarrow$ Displays **50** results.

### 3.2. Pendapatan (Revenue / Turnover)

- **Concept**: Total gross turnover generated from campaign conversions.
- **Formula**:
  $$\text{revenue} = \text{results\_count} \times \text{average\_order\_value}$$
- **Mockup Verification**:
    - Example 1: `6.382978... × Rp 10,000` = `Rp 63,829.78` $\rightarrow$ Displays **Rp 63.830** (standard Indonesian currency grouping).
    - Example 2: `50 × Rp 500,000` = **Rp 25.000.000**.

### 3.3. Keuntungan (Net Profit from Ads / Margin)

- **Concept**: Net monetary gain or loss directly attributable to the advertising campaign after deducting ad spend.
- **Formula**:
  $$\text{profit} = \text{revenue} - \text{monthly\_ad\_spend}$$
- **Mockup Verification**:
    - Example 1: `Rp 63,830 - Rp 1,500,000` = **-Rp 1.436.170** (Net Loss).
    - Example 2: `Rp 25,000,000 - Rp 5,000,000` = **Rp 20.000.000** (Net Profit).

### 3.4. Laba atas Investasi (Return on Investment - ROI %)

- **Concept**: Standard financial Return on Investment percentage measuring the campaign net profitability relative to the capital invested in advertising.
- **Distinction (ROI vs. ROAS)**:
    - **ROAS (Return on Ad Spend)** measures gross efficiency: $\frac{\text{Revenue}}{\text{Ad Spend}} \times 100\%$.
    - **ROI** measures net gain: $\frac{\text{Revenue} - \text{Ad Spend}}{\text{Ad Spend}} \times 100\% = (\text{ROAS} - 1) \times 100\%$.
    - As observed in `ui2.png`: Revenue = `25M`, Spend = `5M`, Net Profit = `20M`. $\frac{20\text{M}}{5\text{M}} \times 100\% = \mathbf{+400.0\%}$. This confirms the design uses authentic **ROI**, not gross ROAS.
- **Formula**:
  $$\text{roi\_percentage} = \begin{cases} \frac{\text{profit}}{\text{monthly\_ad\_spend}} \times 100\%, & \text{if } \text{monthly\_ad\_spend} > 0 \\ 0\%, & \text{if } \text{monthly\_ad\_spend} = 0 \end{cases}$$
- **Mockup Verification**:
    - Example 1: `(-1,436,170 / 1,500,000) * 100` = **-95.7%** (Status: _"Perlu Optimasi"_).
    - Example 2: `(20,000,000 / 5,000,000) * 100` = **+400.0%** (Status: _"Kampanye Menguntungkan"_).

### 3.5. CPR Target (Target Cost Per Result Benchmark)

- **Concept**: Maximum sustainable cost per acquisition benchmark. Industry best-practice for digital products recommends keeping acquisition costs below 30% of product price to preserve operating margins.
- **Formula**:
  $$\text{cpr\_target} = 0.30 \times \text{product\_price}$$
- **Mockup Verification**:
    - Example 1: `30% × Rp 50,000` = **Rp 15.000**.
    - Example 2: `30% × Rp 500,000` = **Rp 150.000**.

### 3.6. Pendapatan per Result & Margin per Result

- **Pendapatan per Result**: Direct unit revenue, equal to `average_order_value`.
- **Margin per Result**:
  $$\text{margin\_per\_result} = \text{average\_order\_value} - \text{cpr}$$
- **Mockup Verification**:
    - Example 1: `Rp 10,000 - Rp 235,000` = **-Rp 225.000**.
    - Example 2: `Rp 500,000 - Rp 100,000` = **Rp 400.000**.

## 4. Wawasan Utama (Dynamic Strategic Insights)

The calculator automatically evaluates campaign health and yields 3 actionable recommendations:

1. **ROI Evaluation**:
    - If `roi_percentage >= 0`: _"ROI sangat baik! Kampanye Anda sangat menguntungkan."_
    - If `roi_percentage < 0`: _"Kampanye perlu optimasi. Fokus pada pengurangan CPR atau peningkatan nilai pesanan."_
2. **CPR Target Comparison**:
    - If `cpr <= cpr_target`: _"CPR Anda berada dalam kisaran sehat (30% dari harga produk)."_
    - If `cpr > cpr_target`: _"Pertimbangkan untuk menurunkan CPR Anda untuk meningkatkan profitabilitas. Target CPR sebaiknya sekitar 30% dari harga produk."_
3. **Budget Projection**:
    - _"Dengan budget Rp [spend] juta/ribu, Anda dapat menghasilkan sekitar [results] results. Setiap result menghasilkan margin Rp [margin_per_result]."_

## 5. Numeric Rules & Edge-Case Protection

1. **Zero CPR Handling**:
    - If `cpr <= 0`, division by zero is intercepted. Result count defaults to `0`, revenue to `0`, profit to `-monthly_ad_spend`, and ROI to `-100%`.
2. **Zero Ad Spend Handling**:
    - If `monthly_ad_spend == 0`, ROI defaults to `0.0%` with zero results and profit.
3. **Formatting Standards**:
    - Currency: Indonesian Rupiah formatting `Rp 1.500.000` using standard dot thousands separators.
    - Percentage: Fixed 1 decimal place with explicit `+` or `-` prefix (e.g. `+400.0%`, `-95.7%`).
4. **Rounding Policy**:
    - Currency calculations round half-up to nearest integer IDR.
    - Results count for display is floor or round to whole integer.
